gittutorial

    A local project → GitHub, start to finish

    Learn Git by
    typing it once.

    Nine commands stand between a folder on your machine and a repository on GitHub. This guide walks you through every one — download, configure, commit, push.

    Start the tutorial
    bash — my-project
    01

    Get the software

    Download Git

    Git is free and open source. Pick your operating system on the official page and download it.

    git-scm.com/install
    02

    Run the installer

    Install Git

    The setup wizard has a lot of screens. The defaults are fine for almost everyone.

    Windows

    Run the .exe and keep the default options.

    macOS

    Run the .pkg, or skip this — Homebrew already installed it.

    Linux

    Already installed by your package manager.

    Verify — open a fresh terminal and run 
    git --version
    03

    One-time setup

    Configure your identity

    Git stamps every commit with a name and email. Set them globally so you only do this once per machine.

    Set your name 
    git config --global user.name "Your Name"
    Set your email 
    git config --global user.email "you@example.com"

    Use the same email address as your GitHub account so your commits are linked to your profile. Swap in your real name and email before running these.

    04

    Set the stage

    Create a repository & open the terminal

    You need an empty repository on GitHub, and a terminal open inside your project folder on your machine.

    On GitHub

    1. Click the + icon in the top right, then New repository.
    2. Give it a name and leave it public or private, your choice.
    3. Don't add a README, .gitignore, or license — leave the repo completely empty.
    4. Click Create repository and keep the page open; you'll need the URL it shows you.

    On your machine

    1. Windows — open your project folder, right-click inside it, and choose "Git Bash Here."
    2. macOS / Linux — open Terminal and run cd into the project folder.
    3. Confirm you're in the right place by running pwd.
    05

    Track your files

    Initialize and stage

    Turn the folder into a Git repository, then stage every file so it's ready to be committed.

    Initialize the repository 
    git init
    Stage every file 
    git add .

    The dot means "everything in this folder." Files listed in a .gitignore are skipped automatically.

    06

    Save a snapshot

    Commit your changes

    A commit is a saved checkpoint with a message describing what changed.

    Commit staged files 
    git commit -m "Initial Commit"

    Keep messages short and in the present tense — you can write more detail in the body for later commits.

    07

    Name your branch

    Rename to main

    Older versions of Git default to a branch called master. Rename it to main to match GitHub's convention.

    Rename the current branch 
    git branch -M main
    08

    Point to GitHub

    Add the remote

    Link your local repository to the empty one you created on GitHub.

    Add the remote named "origin" 
    git remote add origin https://github.com/username/repo.git

    Find this URL on your new repo's page under "…or push an existing repository from the command line."

    09

    Ship it

    Push to GitHub

    Upload your commit and set origin as the default remote for this branch.

    Push and set upstream 
    git push -u origin main

    Git may open a browser window to sign in the first time. After that, -u means future pushes only need git push.

    The full sequence

    Every command from this guide, in order, ready to paste into your terminal.

    full-setup.sh 
    git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git init
git add .
git commit -m "Initial Commit"
git branch -M main
git remote add origin https://github.com/username/repo.git
git push -u origin main
